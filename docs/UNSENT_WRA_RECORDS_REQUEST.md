# 水利署資料與測站紀錄請求草稿 — 未寄送

**狀態：僅供專案負責人審閱；未寄送。** 請求目的是釐清雲林縣土庫國中同址 GNSS、磁環分層沉陷井及地下水壓力井的觀測定義與維護紀錄，以便建立可檢驗的地表與深度對應模型。若資料涉及限制，請先提供公開版本、欄位定義、資料取得程序或負責窗口。

## 測站與公開資料定位

- GNSS 站 `A130600LSTKJS`，土庫國中，公開站位 TWD97 E 187770.14、N 2620603.69 m；[測站基本資料](https://data.gov.tw/dataset/36693)。
- 磁環井 `A130600GWMWTKJS`，土庫國中，公開報告站位 TWD97 E 187771、N 2620610 m；[2003 安裝報告](https://web.wra.gov.tw/wralib/WraLib/wSite/books_41979)、[2017 交通部報告](https://www.iot.gov.tw/uploads/asset/data/661982b7367376304acd4ed0/B1068760.pdf)。
- 土庫地下水觀測井代號末碼 `09050321`、`09050331`、`09050341`，公開資料列示約 90、185、269 m 深；請確認完整站碼及與磁環井及 GNSS 基點的關係。
- [GNSS 高程公開資料](https://data.gov.tw/dataset/36694) 的 `height` 欄位標為公尺，但公開欄位說明未明示垂直基準與高程種類。

## 請提供或確認的紀錄

1. **GNSS 觀測定義與處理版本。** `height` 是橢球高、正高或其他高程？使用何種垂直基準、參考框架及期別、起算站、地球動力或區域運動修正、天線高與相位中心修正？每日值的解算、品質旗標、單日不確定度、重處理規則、發布版本與原始精度為何？請提供自 2020 年起的資料字典、處理說明、版本紀錄及可公開的品質旗標。
2. **GNSS 設備與基點維護。** 請提供接收機、天線、天線座、基點或周圍建物更換、移動、維修、斷電、重新整置及校測紀錄，特別是 2022-06-16 至 2022-06-18、2023-05-20 至 2023-07-25、2023-12-30 至 2024-01-03、2024-10-30 至 2024-11-05、2025-06-10 至 2025-06-25。公開序列於 2022-06-16/17 為 40.49→40.60 m，2023-12-31/2024-01-01 為 40.58→40.48 m，2024-11-01/03 為 40.41→40.35 m；請確認是否有已知非地表位移原因與修正值，若沒有，也請說明。
3. **GNSS 資料版本差異。** 本地既有下載與目前公開資料在共同的 1,690 個日期中，2025-02-01 分別為 40.4255 m 與 40.37 m，相差 5.55 cm；另有八個共同日期相差超過 1 cm。請提供這些日期的原始值、修改歷程、各版本有效期間、缺測原因及正確使用版本，尤其 2023 年 1 月、2025 年 2 月的缺測或稀疏紀錄。請勿僅提供無版本號的更正表。
4. **磁環井安裝與維護對照。** 2003 安裝表 NO1 深 9.85 m，而本地 2003-12-03 首次測量約 8.775 m，其他 NO2–NO24 的安裝值與首次測值差約 0.064–0.092 m；請提供 NO1 的原始手寫紀錄、基準與更換情況。2017 報告在 2013 與 2015 年列有 NO25 測值，但現有 API 提取只含 NO1–NO24；請提供 NO25/NO26 後續量測、停測、維修、改號、剔除及 API 欄位對照。請說明 GNSS 地表基點、磁環井地表基準與各環深度的測量及垂直基準差異。
5. **地層與壓力井完井資料。** 2003 報告 48.5–50.8 m 樣本為 ML 且 34–51 m 解釋為阻水層，2017 報告 48.3–85 m 表列 SP~GP；請提供原始岩心、取樣與地球物理井測紀錄及後續修訂依據。請提供上述三口壓力井的濾管頂底、井管配置、感測器深度、量測基準、維護與水頭轉換方式，並明示各井是否與模型四個含水層相對應。
6. **同址與深部參考。** 請提供同址或鄰近水準點與 GNSS 基點的定期聯測、地面到最深磁環以下的位移參考、以及任何已發布的深部或區域垂直運動估計與其不確定度。若不存在，請確認目前觀測資料不能直接把地表 GNSS 位移全部歸因於 0–300 m 地層壓密。

可接受機器可讀表、原始 PDF 或已公開網址；請附測站代號、觀測日期、時區、單位、座標與垂直基準、品質旗標、版本日期和變更歷程。這些資料將先用於固定觀測算子與資料品質規則，之後再進行模型驗證；目前沒有提出政策效果已獲驗證的主張。
